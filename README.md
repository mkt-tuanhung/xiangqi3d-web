# Cờ Tướng 3D — Tây Sơn đại phá quân Thanh (Kỷ Dậu 1789)

Chơi ngay: https://mkt-tuanhung.github.io/xiangqi3d-web/

- Cờ tướng luật chuẩn trên chiến trường 3D năm Kỷ Dậu 1789: quân Tây Sơn (Quang Trung Hoàng Đế) đối đầu quân Thanh (Tôn Sĩ Nghị).
- Chơi với máy (Dễ / Vừa / Khó), hai người trên một máy, hoặc **đấu qua mạng**: tạo phòng → đối thủ quét mã QR bằng camera điện thoại.
- **QR khán giả**: người xem quét mã để theo dõi trận trực tiếp.

Repo này chỉ chứa bản build WebGL (Unity 6) để GitHub Pages phục vụ.
